Note on Cross-Compatibility

Whilst the ItsyBitsy M4 Express and ItsyBitsy RP2040 can be utilized interchangeably with either expander to a certain extent, it is paramount to reference the respective pinout diagrams to navigate the nuances in pin functionality and ensure accurate configuration.
